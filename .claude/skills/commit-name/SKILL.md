Предложи короткое сообщение коммита на русском для текущих изменений
в стиле истории репозитория: префикс `feat:` или `fix:`, перечисление
изменений через запятую, в конце `;`. Выведи только сообщение, без пояснений.
Коммит не делай.

Если по списку файлов неясно, что изменилось, посмотри diff нужных файлов.

$ARGUMENTS

Изменённые файлы:
!`git status --short`

Статистика изменений:
!`git diff HEAD --stat`

Последние коммиты для образца:
!`git log --format=%s -5`
